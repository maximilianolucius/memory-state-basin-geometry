## 2. What is now closed as novelty

The following are not viable novelty claims:

- fractional memory requires an enlarged state;
- current physical state is generally not Markov;
- different histories can matter;
- two reachable memory states can have the same current physical vector;
- fractional memory changes resilience/stability landscapes;
- delayed collapse/recovery and hysteresis can be memory-dependent;
- fractional systems can be Markovized in an infinite-dimensional lift.

All have direct or close prior art.
