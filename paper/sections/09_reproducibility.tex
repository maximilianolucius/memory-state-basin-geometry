\section*{Code and reproducibility}

The mathematical argument and every load-bearing inequality used in the main theorem are stated in the article. The public project repository, \url{https://github.com/maximilianolucius/memory-state-basin-geometry}, contains the implementation used for the computer-assisted bounds, exact-rational benchmark data, validation manifests, tests, and deterministic figure-generation scripts. These materials are provided for reproducibility and independent reruns; they are not required as supplementary material for the logical completeness of the proof.

The primary certificate is the \(T=300,\ N=12000\) computation described in \cref{sec:cap}. A second independent \(T=1000,\ N=20000\) run is retained in the repository as redundancy. The arithmetic assumptions and evidence boundary of the current certificate are stated explicitly in \cref{subsec:arithmetic-model}.
