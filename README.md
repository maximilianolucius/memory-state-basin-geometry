# Memory-State Basin Geometry

Applied-mathematics research project on basin geometry in multidimensional Caputo systems.

**Core question:** can two physically reachable fractional-memory states with the same current physical state belong to different asymptotic basins, especially extinction versus survival/coexistence in strong/Double-Allee dynamics?

This repository is an original-research project descended from the theorem-level mapping in `maximilianolucius/fractional-stability-front`.
